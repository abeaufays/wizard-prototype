# Wizard prototype

## Backstory
Motions and Operators in Vim reminded me a bit of Magicka, and I thought it would make a nice wizard / spell casting game, so I decided to make one.

## Requirements
- A terminal with NerdFonts
- Python

## How to run
```uv run wizard-prototype```

## General Ideas
You can move your wizard with `hjkl`   
You can cast spell by selecting an element, a form and a direction  
You can use `Space` to cancel a spell mid-cast  
`q` will quit the game  

### Elements
- `f`: Fire
- `a`: Air
- `i`: Ice

### Forms
- `b`: Ball
- `r`: Ray

### Directions
- `h`: Left
- `j`: Down
- `k`: Up
- `l`: Right

## Current State
There is nothing expect casting spells (the fun is in making it more than playing)
